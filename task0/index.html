Task 0: Navigation Bar

The header is a flex container. The logo stays on the left, while the navigation links stay on the right and remain vertically centered.

Flexbox properties used

  • display: flex creates the flex container.
  • justify-content: space-between separates the logo and navigation.
  • align-items: center centers the elements vertically.
  • gap creates consistent spacing between links.
